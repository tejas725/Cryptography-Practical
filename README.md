# Cryptography Practicals

C implementations of cryptography and encryption algorithms for practical coursework.

## Clone

```bash
git clone <repository-url>
cd <repository-name>
```

## Compile & Run

Compile a program with GCC:

```bash
gcc filename.c -o filename
```

Run it:

```bash
./filename
```

On Windows:

```bash
filename.exe
```

Example:

```bash
gcc caesar.c -o caesar
./caesar
```
